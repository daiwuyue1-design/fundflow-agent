# 研判口径与防错知识

## 受理与完整性

先核文件清单、解析失败、关键列、时间跨度、非正金额与身份未核实比例。损坏/缺列项独立列待核实，不能把未读到的交易算作0。数据演示只用fixtures合成样例。

## 实体与身份

规范账号不等于自然人。身份表与账单自报名要分开，显示名称待核实；旧共用账号检测抽取2–4字中文词，商业备注也会误命中。结合实名登记、终端与实际使用证据人工核对一人多号/一号多人。

## 资金图口径与环

清洗后的tx不等于图有效记录。build四层：平台内转账、自转账、全局重复、双向重复按旧执行过程分项观测；旧打印把后两项合计称“双向流水重复”。双向去重合并相反方向、同额、同5分钟桶，可能损失真实往返；保留该限制并核对原始授权资料。有向环显式阻断判层并保图，本期不SCC凝缩。追线BFS同边可能重复、边界节点仍会带相邻边，链路金额不能重复加总。

## 角色识别决策树

账号 → 资金规模档（使用实际百分位与样本数） → 净流向/过路率 → 出入度 → 对手类型与层级 → 角色候选 → 反例核对：

| 候选 | 校验规则 | 反例与边界 |
|---|---|---|
| 高层代理嫌疑 | 高流入百分位、多下游、上游收紧与拓扑规则均引用实际三元组；需核下级投注账号与利润分成 | 正常商户、集中代发工资也高规模多对手；图资金边不是网站上下级账号证据 |
| 二/三级代理嫌疑 | 聚类初始结果结合净流向、出入度加强与拓扑修正；对应规则看05_tiers.json | 小样本初始通道不全；一笔大额借款不能当代理 |
| 赌客线索 | 净流出、低度数、纯充值或返奖；需投注或实际参赌证据 | 消费充值、游戏购买、普通借贷也可能符合 |
| 做账/代收付线索 | scan_structure原支付对象数、金额稳定性、关键词及命中字段；核手续费来源 | 工资、佣金、分红也会命中，不据单一关键词推罪名 |
| 过路/水房/跑分线索 | detect_laundering五维实际得分、最低流量、命中说明；结合实际控制人与合法来源 | 正常结算、家庭中转、企业资金归集；境外关键词不证明跨境交易，洗钱特征不直接证明洗钱罪 |
| 共用账号线索 | 只保留旧potential_users/命中，不生成概率 | 备注“虚构测试/合成充值”等也被当姓名；需人工核实 |
| 待定外围 | 低流量低度数或证据不足，列待核实 | 未取得其账单不能说明没有上游/下游 |

## 防错清单

| 风险 | 处理 | 检查类型 |
|---|---|---|
| 跨账单重复计账 | 核四层分项、清洗记录与图有效记录差异，不相加tx与图权重 | 可检查统计；真实重复是否同一交易需人工核对 |
| 循环流水净额虚增 | 有向环阻断判层；追线金额不重复加总 | 可检查DAG；实质往返需人工核对 |
| 平台内转账 | 图排除；洗钱/结构按旧tx可能仍含平台交易，注明口径 | 可检查 |
| 备注中文词误当人名 | 共用账号命中与实际人数分开 | 需人工核对 |
| 小样本无一级初始通道 | 10–29节点k=3/4；<10规则回退仍可能一级；不是全场景“无一级” | 可检查样本/聚类证据 |
| 金额、时间、账号口径不统一 | 每金额注明元/万元转换、范围、统计类型；单位不能暗换 | 可检查标注；自由文本需人工核对 |
| 判层重算遗留旧检测/排名 | 重新classify后重跑detect、scan_structure、rank与export | 可检查缓存/证据索引 |
| 检测失败误写无异常 | 保留检测器状态failed与原因；未命中也不是排除风险 | 可检查；失败后实质调查需人工 |

## 阈值口径与理由

实际判层用自适应百分位：金额p50/p70/p80/p90/p95/p99，度数p70_out_d/p80_out_d/p90_out_d/p80_in_d。500000/50000/5000元是旧常量背景，不是实际判层固定门槛，不据此自造规则。覆盖真实thresholds需给出偏离理由并等待明确确认，检查单调性，重跑依赖步骤。

洗钱最低总流量30000元，过路率out/in≥0.8且净余额/in≤0.15；24小时窗口转出达到单次收款0.7；整千比例≥0.7且总流量≥50000元；单线入出度≤2且流入≥50000元并满足上下游层级条件。A境外≥3笔40分/≥1笔25分，B过路率×25，C20，D整数比×15，E15；100封顶。嫌疑规则以工具返回原规则为准，尤其旧“境外≥1且flag≥1”并不要求另一个特征。缺时间或owner视角缺记录降低可检出性，不自动补推。上述均算法参数，不是法定数额门槛。

## 报告与表述

结论引用工具依据；表述用线索/嫌疑/特征。固定“层级认定及依据”章名是模板名，正文仍用“层级嫌疑”；法源原文与分析结论分开。金额是流水还是赌资须明示；不以账号数代实际人数。问题、检测失败、冲突与未提供Trace独立列出。
