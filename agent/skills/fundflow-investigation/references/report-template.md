# 固定八章报告模板

`06_report.html`按以下顺序；“层级认定及依据”是固定章名，正文只写层级嫌疑与证据。

1. 数据来源与完整性：文件、失败、缺列、身份核验、单位/时间/账号范围、平台内转账与去重口径。
2. 组织结构：节点边数、资金关联、结构原命中及失败；资金关系与组织关系分开。
3. 层级认定及依据：逐账号线索/嫌疑，指标值/百分位/适用规则与反例核对，实际覆盖参数及确认记录。
4. 资金穿透：目标/种子、深度、上游群、旧BFS重复边与边界限制，账单记录待核；未追线注明未执行。
5. 洗钱线索：是否执行、每节点五维贡献/阈值/命中、最低流量与数据缺失；特征不等于罪名。
6. 重点人员：排名及各维构成、核查优先级、单账号画像；无检测不写无风险。
7. 待核实事项：解析失败、身份不明、检测器失败、重复/环、口径冲突、法源待核、Trace缺失。
8. 侦查建议：针对待核实事项提出所需材料与复核步骤，不替代司法结论。

报告与 `06_evidence_index.json` 一起交付。新增可回溯数字采用例如 `<span data-tool="04_graph_stats" data-pointer="/结论/节点数">16</span>`；pointer指向证据索引“工具结果”下的实际JSON路径，正文值不得只写data属性而显示不同数值。初版检查只覆盖这类标注，不是整份自由文本数值核验。

金额单位/时间范围/账号范围/金额类型/平台内转账写入HTML的 `script#report-scope[type=application/json]`，与证据索引“口径”一致，同时以可见文字说明。法源摘要独立blockquote并带文号条款与待核状态，禁止把待核摘要当精确官方引文。Trace引用由调用方提供，状态注明是否核验。
